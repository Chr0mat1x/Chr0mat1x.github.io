1. Строка как тип данных

Строка — упорядоченная последовательность символов: букв, цифр, пробелов, знаков. В Python это отдельный тип str.

  • Упорядоченность: у каждого символа есть номер (индекс), порядок фиксирован.
  • Неизменяемость: нельзя заменить символ «на месте» — можно собрать новую строку.
  • Итерируемость: строку можно перебирать циклом for.
  • Длина: len(s) — количество символов.

Строка может быть пустой: "", её длина 0 — это нормальное значение.

ТипПримерСмысл

str"42"текст

x = "42"   # строка
y = 42     # число

print(type(x))  # <class 'str'>
print(x + x)    # 4242  (склейка!)
print(y + y)    # 84    (сложение)
print(x * 2)    # 4242  (повтор)

2. Кавычки и длина строки

Три вида кавычек

a = 'Python'        # одинарные
b = "Python"        # двойные — то же самое
c = "Он сказал: 'ок'" # вложенные
d = """Строка
из нескольких
строк"""

Кавычки обязаны быть парными. Одинарные и двойные равнозначны. Тройные — для многострочного текста и документации.

Длина строки: len()

s = "Python"
print(len(s))       # 6

empty = ""
print(len(empty))   # 0

word = "кот"
print(len(word))    # 3
Строкаlen()
"Python"6
"кот"3
""0
" " (пробел)1

len() считает символы, а не байты: пробел — тоже символ. Последний символ имеет индекс len(s) - 1 (или просто -1).

3. Индексация

Первый символ имеет индекс 0. Доступ к символу — квадратные скобки: s[i].

s = "Python"
#      P  y  t  h  o  n
#      0  1  2  3  4  5   ← индексы
#     -6 -5 -4 -3 -2 -1   ← с конца

print(s[0])    # P
print(s[4])    # o
print(s[-1])   # n  (последний)
print(s[-2])   # o  (предпоследний)
ВыражениеРезультатСмысл
s[0]Pпервый
s[2]tтретий
s[-1]nпоследний
s[len(s)-1]nто же, что s[-1]
IndexError. s[6] — ошибка: индексы идут от 0 до len(s)-1.

4. Срезы

s[начало : конец : шаг]
  • начало — с какого индекса (включительно), по умолчанию 0;
  • конец — до какого индекса (не включая), по умолчанию до конца;
  • шаг — через сколько символов, по умолчанию 1; может быть отрицательным.
s = "Программирование"

s[0:4]     # Прог
s[4:]      # раммирование
s[:4]      # Прог
s[:]       # вся строка (копия)
s[0:8:2]   # Пorm  — каждый второй
s[::-1]    # еинавориммаргорП
s[-4:]     # ние
s[3:3]     # ""  (пустая)
ШаблонЧто делает
s[:n]первые n символов
s[-n:]последние n символов
s[::2]каждый второй
s[::-1]переворот строки
Срез никогда не выбрасывает ошибку по границам: "abc"[0:99] → "abc". Срез всегда создаёт новую строку.

6. Методы строк

Вызов через точку: строка.метод(). Все методы возвращают новую строку.

МетодПример → результат
.upper()"abc".upper() → ABC
.lower()"ABC".lower() → abc
.capitalize()"привет мир" → Привет мир
.title()"привет мир" → Привет Мир
.strip()" hi ".strip() → hi
.lstrip() / .rstrip()убрать пробелы слева / справа
.find(x)"Python".find("t") → 2 (-1 если нет)
.index(x)как find, но при отсутствии — ошибка
.count(x)"ааба".count("а") → 3
.replace(a,b)"кот".replace("к","б") → бот
.startswith(x)"file.py".startswith("file") → True
.endswith(x)"file.py".endswith(".py") → True
.split()"я и ты".split() → ['я','и','ты']
sep.join(lst)"-".join(['a','b']) → a-b
Важно: строки неизменяемы — s.upper() не меняет s, а возвращает новую строку. Нужно присвоить: s = s.upper(). Проверки .isdigit(), .isalpha(), .isspace() возвращают True/False.

7. Форматирование строк

# 1. склейка (неудобно)
print("Имя: " + name + ", возраст: " + str(age))

# 2. .format()
print("Имя: {}, возраст: {}".format(name, age))

# 3. f-строка (лучший способ)
print(f"Имя: {name}, возраст: {age}")
ЗаписьРезультат
f"{x:.2f}"2 знака после точки: 3.14
f"{x:>8}"по правому краю, ширина 8
f"{x:<8}"по левому краю
f"{x:^8}"по центру
f"{n:05d}"число с ведущими нулями: 00042

Внутри {} можно писать выражения: f"{2+3*4}" → 14.

9. Перебор строки

По символам

word = "кот"
for ch in word:
    print(ch)
# к
# о
# т

По индексам

word = "кот"
for i in range(len(word)):
    print(i, word[i])
# 0 к
# 1 о
# 2 т

С номером: enumerate

for i, ch in enumerate("кот"):
    print(i, ch)

Аккумулятор: собираем новую строку

word = input("Слово: ")
res = ""
for ch in word:
    if ch.lower() in "аеёиоуыэюя":
        res += ch
print(f"Гласные: {res}")

Итог и шпаргалка

  • Строка — тип str, последовательность символов, неизменяема.
  • Индексы с нуля: s[0] … s[-1]. Срез s[нач:кон:шаг]; s[::-1] — переворот.
  • Операции: +, *, len(), in, ==.
  • input() даёт строку → приводим тип: int(), float().
  • Методы: регистр .upper() .lower() .title() .capitalize(); пробелы .strip() .lstrip() .rstrip(); поиск .find() .index() .count() .startswith() .endswith(); изменение .replace(); разбор .split(), sep.join(); проверки .isdigit() .isalpha() .isspace(); вывод f"{значение}", f"{x:.2f}".
Строка → индекс/срез → метод → новая строка → вывод через f-строку
