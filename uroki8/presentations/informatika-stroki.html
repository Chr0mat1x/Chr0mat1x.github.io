01

Строка как тип данныхЧто такое str и чем он отличается от числа

Строка — упорядоченная последовательность символов: букв, цифр, пробелов, знаков препинания, эмодзи. В Python это отдельный тип — str.

  • Упорядоченность: у каждого символа есть номер (индекс), порядок фиксирован.
  • Неизменяемость: нельзя заменить символ «на месте» — можно собрать новую строку.
  • Итерируемость: строку можно перебирать циклом for.
  • Имеет длину: len(s) — количество символов.
Строка может быть пустой: "". Её длина — 0. Это не ошибка и не «ничего», а вполне нормальное значение.
ТипПримерСмысл
int42целое число
float3.14дробное число
str"42"текст
boolTrueистина / ложь
x = "42"   # строка
y = 42     # число

print(type(x))  # <class 'str'>
print(x + x)    # 4242  (склейка!)
print(y + y)    # 84    (сложение)
print(x * 2)    # 4242  (повтор)

Зачем строки

Имена, адреса, тексты, пароли, ответы пользователя — почти любой ввод с клавиатуры приходит строкой.

Ключевая мысль

Строка и число с виду похожи ("42" и 42), но ведут себя по-разному. Тип определяет поведение.

Проверка

type(x) показывает тип. Полезно при отладке, когда «не работает» сложение.

ИндексацияНумерация с нуля · отрицательные индексы · IndexError

Первый символ имеет индекс 0. Доступ к символу — квадратные скобки: s[i].

s = "Python"
#      P  y  t  h  o  n
#      0  1  2  3  4  5   ← индексы
#     -6 -5 -4 -3 -2 -1   ← с конца

print(s[0])    # P
print(s[4])    # o
print(s[-1])   # n  (последний)
print(s[-2])   # o  (предпоследний)
IndexError. s[6] — ошибка: индексы идут от 0 до len(s)-1. Последний символ надёжнее брать как s[-1].
ВыражениеРезультатСмысл
s[0]Pпервый
s[2]tтретий
s[-1]nпоследний
s[len(s)-1]nто же, что s[-1]

Правило

Индекс — это смещение от начала. Символ №0 — первый, значит символ №len(s) уже не существует.

Проверка на палиндром

w = "шалаш"

04

Срезыs[начало:конец:шаг] · правило «конец не входит»

s[начало : конец : шаг]
  • начало — с какого индекса (включительно), по умолчанию 0
  • конец — до какого индекса (не включая), по умолчанию до конца
  • шаг — через сколько символов, по умолчанию 1; может быть отрицательным
Срез никогда не выбрасывает ошибку по границам: "abc"[0:99] → "abc". Срез всегда создаёт новую строку.
s = "Программирование"

s[0:4]     # Прог
s[4:]      # раммирование
s[:4]      # Прог
s[:]       # вся строка (копия)
s[0:8:2]   # Пorm  — каждый второй
s[::-1]     # еинавориммаргорП
s[-4:]     # ние
s[3:3]     # ""  (пустая)
ШаблонЧто делает
s[:n]первые n символов
s[-n:]последние n символов
s[::2]каждый второй
s[::-1]переворот строки

Нельзя смешивать

"5" + 3 → TypeError. Нужно привести к одному типу: int("5") + 3.

"Да" == "да" → False. Сравнение учитывает регистр символов.

Коды символов

07

Форматирование строкf-строки · выравнивание · вывод чисел

Три способа вставить значение

# 1. склейка (неудобно)
print("Имя: " + name + ", возраст: " + str(age))

# 2. .format()
print("Имя: {}, возраст: {}".format(name, age))

# 3. f-строка (лучший способ)
print(f"Имя: {name}, возраст: {age}")

Перед кавычкой ставится f, значения — в {фигурных скобках}. Внутри можно писать выражения: f"{2+3*4}" → 14.

Полезные приёмы внутри {}

ЗаписьРезультат
f"{x:.2f}"2 знака после точки: 3.14
f"{x:>8}"выравнивание по правому краю, ширина 8
f"{x:<8}"по левому краю
f"{x:^8}"по центру
f"{n:05d}"число с ведущими нулями: 00042
f"{p}%"процент прямо в тексте

Правило хорошего тона

Для сборки текста с данными используй f-строки: код короче, читается как обычное предложение, не нужен str().

09

Перебор строкиfor по символам · по индексам · enumerate · аккумулятор

По символам

word = "кот"
for ch in word:
    print(ch)
# к
# о
# т

Самый простой способ, когда нужны только символы.

По индексам

word = "кот"
for i in range(len(word)):
    print(i, word[i])
# 0 к
# 1 о
# 2 т

Нужен, когда важен номер символа (например, позиция).

С номером: enumerate

for i, ch in enumerate("кот"):
    print(i, ch)
# 0 к
# 1 о
# 2 т

Короче, чем range(len(...)).

Аккумулятор: собираем новую строку

word = input("Слово: ")
res = ""
for ch in word:
    if ch.lower() in "аеёиоуыэюя":
        res += ch
print(f"Гласные: {res}")

Идея

Строка неизменяема, поэтому мы не «правим» её, а накапливаем результат в новой переменной. Это базовый шаблон обработки текста: пройти по символам → проверить условие → добавить/посчитать.

Разбор программыАнализ введённого слова по шагам

word = input("Введите слово: ")

print(f"Длина: {len(word)}")
print(f"Первый символ: {word[0]}")
print(f"Последний символ: {word[-1]}")
print(f"Заглавными: {word.upper()}")
print(f"Наоборот: {word[::-1]}")

if word.lower() == word[::-1].lower():
    print("Это палиндром!")
else:
    print("Обычное слово")

Что происходит

  1. input() возвращает строку — с ней сразу можно работать.
  2. len(word) — длина, word[0] / word[-1] — края.
  3. .upper() не меняет word, а возвращает новую строку для вывода.
  4. word[::-1] — копия в обратном порядке.
  5. Сравнение == проверяет палиндром; .lower() убирает разницу регистра.
Пример: "шалаш" → перевёрнутая тоже "шалаш" → палиндром.
