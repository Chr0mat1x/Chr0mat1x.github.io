# Чекушка для Меллстроя

Пародия на Cut the Rope: режь верёвки свайпом и корми Меллстроя чекушкой.

- 6 уровней, звёзды за сбор
- физика верёвок и бутылки на canvas, без библиотек
- спрайты вырезаны из видео, мемные гифки «сладость, приятность и вкусность» и «браво, босс»

## Запуск

Открыть `index.html` или поднять статику:

```bash
python3 -m http.server 12000
```

## Структура

| файл | что внутри |
| --- | --- |
| `index.html` | разметка, canvas |
| `assets.js` | загрузка картинок |
| `art.js` | отрисовка спрайтов, верёвок, фонов |
| `levels.js` | раскладка 6 уровней |
| `game.js` | игровой цикл, физика, оверлеи победы/проигрыша |
| `audio.js` | звуки на WebAudio |
| `assets/` | спрайты и спрайт-листы мемных нарезок |
